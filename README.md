# 作业看板 HomeworkBoard

一个放在 Windows 桌面角落的轻量作业看板：按截止时间从近到远排列，清楚显示科目、平台和剩余时间。

![作业看板预览](preview.png)

没有作业时，它会缩成一块接近透明的淡白色卡片：

![空看板](preview-empty.png)

## 快速开始

1. 把 `HomeworkBoard.exe` 放到一个以后不会删除的文件夹里，例如 `D:\Tools\HomeworkBoard\`。
2. 双击 `HomeworkBoard.exe` 即可运行，无需安装。
3. 如果希望开机自动启动，请先确认程序已经放在固定位置，再到「设置」中勾选开机启动并保存。

> 系统要求：Windows 10 / 11。程序使用系统自带的 .NET Framework 4.8，不额外安装运行库。
>
> 这是本地编译的未签名小程序。如果 Windows 首次运行时弹出“已保护你的电脑”或“未知发布者”，点“更多信息 → 仍要运行”即可。

## 使用方法

- 点击右上角橙色 **+** 添加作业。
- 填写作业名称、科目，选择平台和截止日期 / 小时。
- 平台选项可以自己扩充：在添加窗口中点平台右侧的 **+**，或到「设置 → 作业平台」里添加、删除。
- 作业会始终按截止时间升序排列；每张卡片显示科目、平台、截止时间，以及剩余时间或逾期提示。
- **双击**作业可以编辑；**右键**作业可以编辑或删除。
- 按住窗口顶部空白处可以拖动看板，位置会自动记住。
- 点击顶部滑杆图标进入「设置」，点击短横线最小化。

## 设置

- **开机时自动启动**：写入当前用户的 Windows 启动项，不需要管理员权限。
- **最小化或关闭时**：
  - 隐藏到系统托盘：程序继续在后台运行，双击托盘图标可以重新打开。
  - 直接退出程序：最小化或关闭窗口时结束程序。
- **重置看板到桌面默认位置**：如果窗口不小心拖到屏幕外，可以用这个功能找回。

> 如果之后移动了 `HomeworkBoard.exe` 的位置，请重新打开设置，确认开机启动选项后保存一次，让启动项指向新位置。

## 空看板的效果

没有任何作业时，窗口会缩成一小块接近透明的淡白色卡片。把鼠标移上去会暂时恢复清晰，方便你点 **+** 添加作业；移开后会重新变淡。

## 设计说明

- 看板**不会强制置顶**，所以打游戏或全屏工作时不会挡住画面。需要查看时，点一下任务栏上的「作业看板」图标即可把它带到前面。
- 程序是原生 C# / WinForms 小程序，没有内置浏览器或 Electron，常驻内存大约 30–50 MB，空闲时只有一个每分钟触发一次的轻量重绘计时器。
- 作业和设置保存在：`%APPDATA%\HomeworkBoard\data.xml`。删除这个文件夹即可清空数据；升级程序时不会丢失。

## 开发者

源码位于 `src/`，使用 Windows 自带的 .NET Framework 4.x 编译器构建：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

输出位于 `dist\HomeworkBoard.exe`。构建脚本会重新生成 `build/app.ico` 并编译为单文件 EXE。
