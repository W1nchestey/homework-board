作业看板 HomeworkBoard v1.0
================================

一个放在 Windows 桌面角落的轻量作业看板：按截止时间从近到远排列，清楚显示科目、平台和剩余时间。


【开始使用】

1. 把 HomeworkBoard.exe 放到一个以后不会删除的固定文件夹，例如：
   D:\Tools\HomeworkBoard\

2. 双击 HomeworkBoard.exe 运行。

3. 程序第一次运行会在桌面上显示一块淡白色卡片。把鼠标移上去，
   卡片会恢复清晰。

4. 点击右上角橙色的 + 添加作业：
   - 输入作业名称和科目
   - 选择平台
   - 选择截止日期和小时
   - 点击“添加作业”

平台选项可以自己增加：在添加窗口中点平台右侧的 +，
或打开“设置 → 作业平台”添加、删除。

系统要求：Windows 10 / 11。
程序使用 Windows 自带的 .NET Framework 4.8，不需要另外安装运行库。

如果 Windows 首次运行时提示“已保护你的电脑”或“未知发布者”，
点“更多信息 → 仍要运行”即可。这是本地编译的未签名程序。


【日常操作】

- 作业自动按截止时间升序排列。
- 卡片上会显示科目、平台、截止日期和剩余时间；逾期会用红色标出。
- 双击作业：编辑。
- 右键作业：编辑或删除。
- 按住窗口顶部空白处：拖动看板。
- 滚轮：作业较多时滚动查看。
- 顶部滑杆图标：打开设置。
- 顶部短横线：最小化（按设置隐藏到托盘或退出）。


【设置】

开机时自动启动
    勾选并保存后，登录 Windows 时会自动启动作业看板。
    注意：如果移动了 HomeworkBoard.exe 的位置，请重新打开设置，
    确认开机启动选项后保存一次。

最小化或关闭时
    - 隐藏到系统托盘：程序继续在后台运行，双击托盘图标恢复。
    - 直接退出程序：最小化或关闭窗口时结束程序。

重置看板到桌面默认位置
    如果窗口被拖到屏幕外，可以用这个选项找回。


【关于空看板】

没有作业时，窗口会缩成一小块接近透明的淡白色卡片，不会干扰桌面。
鼠标移上去会暂时恢复清晰，方便添加作业；移开后会重新变淡。


【关于置顶】

看板不会强制置顶，所以打游戏或全屏工作时不会挡住画面。
需要查看时，点一下任务栏上的“作业看板”图标即可把它带到前面。


【数据位置】

作业和设置保存在：
    %APPDATA%\HomeworkBoard\data.xml

删除这个文件夹即可清空数据；升级程序时不会丢失。
程序常驻内存约 30–50 MB，空闲时只有一个每分钟触发一次的轻量刷新计时器。


【常见问题】

Q: 双击没有反应？
A: 程序可能已经隐藏到系统托盘，或者已经在运行。检查任务栏和托盘区。
   本程序同时只允许运行一个实例。

Q: 开机启动没有生效？
A: 请先把 exe 放到固定文件夹，再到设置里重新勾选并保存。
   少数安全软件会拦截写入启动项，请允许本程序修改当前用户的启动项。

Q: 数据会丢吗？
A: 保存采用临时文件替换方式，并保留 data.xml.bak 备份。
   如果 XML 损坏，程序会尝试备份损坏文件并使用空看板启动。
